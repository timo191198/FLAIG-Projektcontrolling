# FLAIG-Projektcontrolling

Klickbarer High-Fidelity-Prototyp für die digitale Nachkalkulation abgeschlossener Innenausbauprojekte.

## Lokal starten

```bash
npm install
npm run dev
```

Anschließend ist die Anwendung unter `http://127.0.0.1:4173/` erreichbar.

## Produktions-Build

```bash
npm run build
npm run preview
```

Alle benötigten Marken-Assets, Schriftarten, Demodaten und Bibliotheken liegen lokal. Nach der einmaligen Installation ist für die Präsentation keine Internetverbindung erforderlich.

## Enthaltene Bereiche

- Dashboard mit aggregierten Zeit- und Kostenkennzahlen
- Auftragsübersicht mit Suche, Filtern und Sortierung
- Auftragsübergreifende Arbeitsplatzanalyse mit Detailpanel
- Individuelle Nachkalkulation für drei Demo-Aufträge
- Dokumentation von Ursachen und Erkenntnissen
- Dynamische Berechnung aller Kennzahlen aus einem zentralen Datensatz

Die dargestellten Beträge sind kalkulatorische Arbeitszeitkosten und keine vollständige Projektrentabilitätsrechnung.
